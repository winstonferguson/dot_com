## Problem

Saw & Sew sold highly customisable furniture. Each customer's configuration had to be priced, sold and passed to production, which was outsourced.

## What I built

- **Rule-based parametric models,** so one model could generate many product variations. That made cataloguing and selling made-to-order furniture practical.
- **An online shop** on Rails 7 and Spree, with Stripe for payments.
- **A parametric configurator** using ShapeDiver, so customers set sizes and options and see the product change.
- **A product metadata framework** that describes each product's options for the configurator and the shop.
- **AI-generated input values** for the configurator, from what the customer asks for, and **AI for bespoke fabric designs,** so customers could preview them in AR.
- **A credit system** that tracks each customer's AI usage.
